# 🧮 Calculator Web Application

This is my first web development project — a simple and user-friendly Calculator Web Application.

## 📌 About the Project

I created this calculator to practice the basics of web development and JavaScript. It can perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

## 🚀 Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear button
- Delete button
- Responsive design
- Simple and easy-to-use interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
